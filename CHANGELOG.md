# Changelog

## 1.0.0 - Initial HUI development build

- Rebuilt the addon from a clean source tree with Hybrid and Pure Gamepad modes.
- Kept presentation overrides active only in the player world; wrappers become pass-through during loading transitions.
- Added detected restricted-screen safeguards for Crown Store/market, Scrying, and Tribute.
- Added a lockpicking exception before ESO chooses the lockpick scene.
- Added pointer-fragment ownership and fail-safe directional stick consumption.
- Added explicit Gamepad Mode On detection (Auto is not accepted).
- Added gamepad keybind preference handling and account-wide settings.
- Added AI disclosure, ADCUI attribution, and LibMousePointer dependency credit.
- Added API 101051 compatibility metadata and a validation/package workflow.
