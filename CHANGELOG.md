# Changelog

## 1.0.0 - Initial HUI development build

- Rebuilt the addon from a clean source tree with Hybrid and Pure Gamepad modes.
- Deferred UI mode overrides, scene hooks, and pointer integration until the player is active in the world.
- Restore native UI preference on player deactivation and on detected restricted UI scenes.
- Added lockpicking exception before ESO chooses the lockpick scene.
- Added safe pointer-fragment ownership and a fail-safe for directional stick consumption.
- Added gamepad keybind preference handling and account-wide settings.
- Added AI disclosure, ADCUI attribution, and LibMousePointer dependency credit.
- Added API 101051 compatibility metadata and a validation/package workflow.
