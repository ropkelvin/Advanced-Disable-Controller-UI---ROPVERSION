## Title: ESO Hybrid UI
## Description: AI-assisted development. Controller-first ESO interface addon. Keep Gamepad Mode On while Hybrid provides a keyboard-layout HUD, controller glyphs and a keyboard-style quickslot wheel. Supported menus, dialogs, map, loot and lockpicking use ESO's native Gamepad UI. The player-interaction wheel retains its keyboard-style presentation in Hybrid. Requires LibAddonMenu-2.0 r43+. Optional: LibGamepadOptions (controller settings page), LibDebugLogger (persistent log output). Inspired by Advanced Disable Controller UI (Lionas; contributions: jc28735250, DoriKyll).
