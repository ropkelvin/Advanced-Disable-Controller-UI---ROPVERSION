## Title: ESO Hybrid UI
## Description: AI-assisted development. Controller-first ESO interface addon. Keep Gamepad Mode On. Modes: native Gamepad; Hybrid (keyboard-layout HUD with native Gamepad menus); Keyboard UI + Controller (normal keyboard presentation throughout with controller input and glyphs where ESO supports them). Requires LibAddonMenu-2.0 r43+. Optional: LibGamepadOptions (controller settings page), LibDebugLogger (persistent log output). Inspired by Advanced Disable Controller UI (Lionas; contributions: jc28735250, DoriKyll).
