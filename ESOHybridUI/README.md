# HUI - ESO Hybrid UI 2.0.1

Keyboard-style ESO menus, driven entirely by the controller, with ESO
Gamepad Mode set to **On** (Settings > Controls). Requires LibMousePointer.

## Controls (in menus)
| Input | Action |
|---|---|
| Left stick | Move pointer (character stays still) |
| A or L3 | Click (A yields to a screen's own A action; L3 always clicks) |
| R3 | Right-click (context menus: Use, Equip, Link, Destroy) |
| Right stick | Scroll lists under the pointer |
| LB / RB | Previous / next main menu category |
| LT / RT | Previous / next tab of the current screen |

## Commands
`/hui status` `/hui hybrid` `/hui gamepad` `/hui tabs` `/hui help`
`/huidebug` records a 90 s log to SavedVariables (then `/reloadui`).

## Notes
Crown Store, Tribute, Scrying and similar restricted screens, and
lockpicking, always use ESO's native presentation and are never modified.
Install: unzip so the folder is `Documents/Elder Scrolls Online/live/AddOns/ESOHybridUI/`.
