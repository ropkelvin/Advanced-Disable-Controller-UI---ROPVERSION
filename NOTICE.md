# Project history and attribution

ESO Hybrid UI is maintained by **RopKelvin**.

This project continues work in the area originally addressed by **Advanced Disable Controller UI** for The Elder Scrolls Online. The upstream project is associated with its original contributors, including **Lionas**, **DoriKyll**, and **jc28735250**. The current repository contains a substantial Update 51 modernization, new Hybrid-mode behaviour, controller prompt handling, map routing, and other changes.

Original upstream project:
https://github.com/Lionas/Advanced-Disable-Controller-UI
