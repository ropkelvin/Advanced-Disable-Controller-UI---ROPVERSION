WHAT IT DOES
Provides native Gamepad mode and a Hybrid mode that keeps ESO's compact keyboard-style gameplay HUD while showing controller prompts. Hybrid retains ESO's native gamepad menus and navigation, with keyboard-style quickslot and player-interaction wheels.

REQUIREMENTS
- The Elder Scrolls Online PC/Mac client.
- LibAddonMenu-2.0 version 43 or newer, installed separately.
- Optional: LibGamepadOptions AddOnVersion 7 or newer for a dedicated ESO Hybrid UI category in the native gamepad Options menu.
- ESO Gamepad Mode should be set to On for the recommended controller-first behavior.

INSTALLATION
Extract the ESOHybridUI folder into Documents/Elder Scrolls Online/live/AddOns.
Do not install this ZIP inside another folder. Enable ESO Hybrid UI in the in-game Add-Ons menu. The keyboard settings panel remains available through LibAddonMenu-2.0.

SAFETY / SCOPE
This addon changes UI presentation and keybind prompt display only. It does not automate combat, send mail, attach gold, trade, or execute gameplay actions on the player's behalf. The optional donation control only opens a mail draft; the player decides whether to send it and whether to attach gold.
